**📄 论文速递**

1. **[T1: 面向长时程任务的终端智能体强化学习（Terminal Agent Reinforcement Learning for Long-Horizon Tasks）](https://huggingface.co/papers/2609.11042)**
提出 T1，一个总参数量 122B 的混合专家模型，通过强化学习专攻终端类长时程任务，面向编码与科学发现等智能体应用场景。

2. **[记忆即规划：以记忆为基的世界-动作建模（Memory as Plans: World-Action Modeling with Memory-Grounded Planning）](https://huggingface.co/papers/2609.11561)**
针对主流机器人策略的马尔可夫假设局限，提出以记忆为基的规划式世界-动作建模，解决复杂操作任务中的非马尔可夫长时程依赖问题。

3. **[递归代码世界模型：通过递归场景程序构建复杂世界（Recursive Code World Models: Building Complex Worlds through Recursive Scene Programs）](https://huggingface.co/papers/2609.11499)**
提出 RCWM 框架，以递归场景程序的方式构建复杂可执行世界模型，解决代码化世界表示中"如何构造复杂世界"的关键问题。

4. **[世界中的世界：用世界模型探索世界（World in World: Explore the World with World Models）](https://huggingface.co/papers/2609.11548)**
面向自回归视频世界模型，提出从新视角探索源视频的灵活控制方法，提升交互式长时程探索的可控性。

5. **[DRG-MAPPO：面向协同空战的分层动态角色图多智能体强化学习](https://huggingface.co/papers/2609.11155)**
将分层结构与动态角色图引入多智能体强化学习，用于协同空战等自主系统复杂决策场景。

6. **[IMO 金牌的开放配方：为奥数训练 Nemotron（An Open Recipe for IMO Gold: Training Nemotron for Olympiad Mathematics）](https://huggingface.co/papers/2609.10712)**
研究后训练与测试时推理设计对自然语言数学证明生成的影响，基于 Nemotron 3 Ultra 训练两个专家检查点冲击奥数竞赛水平。

7. **[CARDEA：面向端到端冠脉造影解读的空间证据可审计推理](https://huggingface.co/papers/2609.06931)**
针对冠脉造影解读观察者差异大的问题，提出基于空间证据的可审计推理方法，提升 AI 解读的一致性与可解释性。

8. **[通过世界模型扩展自动研究智能体（Scaling Automatic Research Agents via World Models）](https://huggingface.co/papers/2608.12564)**
探索以世界模型扩展自动研究（AutoResearch）智能体，使 LLM 能独立完成实证研究流程，是当日热度最高的论文之一。
