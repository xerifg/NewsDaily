**📄 论文速递**

今日论文集中在 Agent 训练、世界模型与 VLA 动作建模三个方向。

1. **[编码 Agent 的 Harness 设计实证研究（An Empirical Study of Harness Design for Coding Agents）](https://huggingface.co/papers/2609.20804)**
系统拆解编码 Agent 的 harness 各组件，揭示其如何将模型能力转化为长周期软件工程表现。

2. **[JEPA-Anything：跨不同世界学习预测模型（JEPA-Anything: Learning Predictive Models across Different Worlds）](https://huggingface.co/papers/2609.20800)**
探索用统一学习原则构建跨域世界模型，突破现有预测模型局限于单一领域的限制。

3. **[RetireOPD：面向 Agent 强化学习的自退役同策略蒸馏（RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning）](https://huggingface.co/papers/2609.20784)**
针对多轮 Agent RL 奖励稀疏问题，提出可自我退役的同策略蒸馏以提供密集 token 级监督。

4. **[重新思考 PPO 中的 Critic 学习：理解与缓解价值平坦化（Rethinking Critic Learning in PPO: Understanding and Mitigating Value Flattening）](https://huggingface.co/papers/2609.18708)**
发现 PPO 中 critic 的价值平坦化现象并提出缓解方法，改善 LLM 强化学习稳定性。

5. **[Agora：以 Git 作为集体自动研究的共享记忆（Agora: Git as Shared Memory for Collective AutoResearch）](https://huggingface.co/papers/2609.18094)**
用 Git 作为多 Agent 自动研究循环的共享记忆，解决各会话从零开始、难以累积的问题。

6. **[ActionPiece：重新思考自回归 VLA 模型的动作分词（ActionPiece: Rethinking Action Tokenization for Autoregressive Vision-Language-Action Models）](https://huggingface.co/papers/2609.18487)**
重新设计 VLA 模型的动作分词方案，兼顾策略训练目标与可执行指令的还原质量。

7. **[基于 VLM Agent 的上下文机器人学习（In-Context Robot Learning with VLM Agents）](https://huggingface.co/papers/2609.19138)**
利用 VLM Agent 的上下文学习能力，让机器人在有限示范下适应陌生环境与任务。

8. **[Zing-0.5：面向可玩世界的实时联合动作与文本控制（Zing-0.5: Toward Playable Worlds with Real-Time Joint Action and Text Control）](https://huggingface.co/papers/2609.17909)**
提出 5B 自回归世界模型，支持用户通过按键与文本实时影响生成世界的演化。
