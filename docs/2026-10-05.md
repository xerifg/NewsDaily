8. **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)**

**📄 论文速递**

今日 arXiv cs.RO 新论文集中在 VLA 策略、世界模型、触觉灵巧操作与长程任务规划等具身智能核心议题。

1. **[面向视觉-语言-动作模型的世界校准提议到动作流（World-Calibrated Proposal-to-Action Flow for Vision-Language-Action Models）](https://arxiv.org/abs/2610.02323)**
针对基于流的 VLA 策略从任务无关各向同性高斯源传输样本的问题，提出世界校准的提议到动作流方法以提升动作生成质量。

2. **[SoTa：用于灵巧操作的柔性触觉皮肤（SoTa: Soft Tactile Skins for Dexterous Manipulation）](https://arxiv.org/abs/2610.02338)**
提出柔性触觉皮肤方案，为机器人策略提供视觉之外的接触信息，以增强灵巧操作能力。

3. **[NEEDLEWORK：以可验证局部缝合离线重写机器人数据（NEEDLEWORK: Offline Rewriting of Robot Data with Verified Local Stitches）](https://arxiv.org/abs/2610.02339)**
针对演示数据中低效或失败片段仍含有效行为的情况，通过轨迹缝合与可验证的局部拼接离线重写机器人数据。

4. **[面向安全人形全身跟踪的滤波器感知微调（Filter-Aware Fine-Tuning for Safe Humanoid Whole-Body Tracking）](https://arxiv.org/abs/2610.02341)**
面向非结构化环境下的人形全身运动安全，提出滤波器感知的微调方法，衔接参考轨迹生成与全身控制。

5. **[SocialVLA：面向 VLA 操作中基于人类反应的失败检测与恢复的社会感知网关（SocialVLA: A Social Perception Gateway for Human-Reaction-Based Failure Detection and Recovery in VLA Manipulation）](https://arxiv.org/abs/2610.02360)**
利用人类观察者的反应作为社会感知信号，帮助 VLA 策略在执行中检测自身失败并触发恢复。

6. **[重新思考面向组合式与上下文内机器人操作的世界-动作模型（Rethinking World-Action Model for Compositional and In-Context Robotic Manipulation）](https://arxiv.org/abs/2610.02368)**
面向长程组合式操作任务，重新审视世界-动作模型的设计，以支持多步骤协同与上下文内泛化。

7. **[自主移动机器人运营物流：作业、调度事件与机器人状态数据集（Autonomous mobile robot operations logistics: a dataset of jobs, dispatch events and robot states）](https://arxiv.org/abs/2610.02428)**
发布生产物流中 AMR 运营的真实数据集，涵盖作业生成、调度事件与机器人状态，为调度与运营研究提供基准。

8. **[RUL-Aware RRT*：面向机械臂的退化均衡运动规划（RUL-Aware RRT*: Degradation-Balanced Motion Planning for Robotic Manipulators）](https://arxiv.org/abs/2610.02469)**
针对长期运行机械臂关节退化不均导致最弱执行器提前失效的问题，提出考虑剩余使用寿命的退化均衡运动规划。

9. **[基于关键时间高斯过程回归的实时事件相机双目视觉里程计（Real-time Event-camera Stereo Visual Odometry via Keytime Gaussian Process Regression）](https://arxiv.org/abs/2610.02601)**
利用事件相机微秒级时间分辨率与高动态范围优势，通过关键时间高斯过程回归实现实时双目视觉里程计。

10. **[DeltaWorld：通过动作条件潜在增量学习的物理一致交互式世界模拟器（DeltaWorld: Physically Consistent Interactive World Simulators via Action-Conditioned Latent Increment Learning）](https://arxiv.org/abs/2610.02691)**
提出以动作条件潜在增量学习构建物理一致的交互式世界模拟器，为机器人规划、策略训练与评估提供可扩展环境。

11. **[月球表面谁在何时去了哪里：识别拜占庭漫游车的取证轨迹分析（Who Went Where When on the Lunar Surface: Forensic Trajectory Analysis to Identify Byzantine Rovers）](https://arxiv.org/abs/2610.02694)**
面向多台独立运行漫游车共享同一部署区域的未来行星任务，提出取证式轨迹分析以识别异常（拜占庭）漫游车。

12. **[GeoScaffold：通过重建学习紧凑几何潜表征以实现高效视觉-语言导航（GeoScaffold: Learning Compact Geometric Latents via Reconstruction for Efficient Vision-Language Navigation）](https://arxiv.org/abs/2610.02697)**
针对流式 Video-LLM 导航策略，通过重建学习紧凑几何潜表征，提升视觉-语言导航的效率。

13. **[AdaTempo：从演示中学习共享相对节奏以实现更快的机器人操作（AdaTempo: Learning Shared Relative Tempo from Demonstrations for Faster Robot Manipulation）](https://arxiv.org/abs/2610.02706)**
针对模仿学习策略继承遥操作演示过慢节奏的问题，提出学习共享相对节奏以实现非均匀加速的更快操作。

14. **[RoboChemGym：面向长程化学操作的协议驱动生成式仿真框架（RoboChemGym: A Protocol-Driven Generative Simulation Framework for Long-Horizon Chemical Manipulation）](https://arxiv.org/abs/2610.02708)**
面向湿实验劳动密集、成本高的问题，提出协议驱动的生成式仿真框架，支撑长程化学操作任务研究。

15. **[RoboBridge：面向仿真到现实迁移的自演化具身智能体框架（RoboBridge: A Self-Evolving Embodied Agent Framework for Sim-to-Real Transfer）](https://arxiv.org/abs/2610.02717)**
针对具身智能从仿真迁移到现实的核心难题，提出自演化具身智能体框架以持续适应真实环境。
