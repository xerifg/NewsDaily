今日论文聚焦 VLA 物理状态建模、多会话 Agent 强化学习、策略迁移蒸馏与 GUI Agent 训练平台等方向。

1. **[Waypoint-OPD：通过门控同策略蒸馏迁移 RL 引发的策略偏移（Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation）](https://huggingface.co/papers/2610.21601)**
提出以教师模型 RL 前后对数概率差作为学生轨迹监督信号，并通过门控机制实现策略偏移的高效迁移。

2. **[VLA-Δ：为视觉-语言-动作模型学习物理状态转移（VLA-Δ: Learning Physical State Transition for Vision-Language-Action Models）](https://huggingface.co/papers/2610.21306)**
针对现有 VLA 模型缺乏物理状态转移建模的问题，提出显式学习状态变化以增强机器人控制泛化能力。

3. **[Mosaic：多会话智能体强化学习（Mosaic: Multi-Session Agentic Reinforcement Learning）](https://huggingface.co/papers/2610.22174)**
突破单会话轨迹假设，面向上下文压缩等场景构建多会话 Agent 强化学习框架。

4. **[OmniVerifier-C1：面向规则约束生成式世界建模的分解式分级验证器（OmniVerifier-C1: Decomposed Graded Verifier for Rule-Governed Generative World Modeling）](https://huggingface.co/papers/2610.22355)**
提出分解式分级视觉验证器，提升复杂组合式多模态场景下生成世界模型的验证鲁棒性。

5. **[MLExpert：面向自主机器学习工程的通用智能体模型（MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering）](https://huggingface.co/papers/2610.22344)**
构建可自主开发与改进 AI 系统的通用 Agent 模型，推进 AI for AI 的递归自我改进路径。

6. **[面向工具调用智能体的轨迹级推测与语义验证（Trajectory-Level Speculation with Semantic Verification for Tool-Using Agents）](https://huggingface.co/papers/2610.21463)**
针对工具调用 Agent 大量常规步骤，提出轨迹级推测解码配合语义验证，在保持质量的同时降低推理成本。

7. **[CarryOn：面向个性化可靠机器人辅助的双环 harness（CarryOn: A Dual-Loop Harness for Personalized and Reliable Robot Assistance）](https://huggingface.co/papers/2610.21453)**
针对通用 VLA 模型缺乏个性化与可靠性问题，设计双环框架提升真实场景机器人辅助能力。

8. **[MAI-Gym：跨移动与电脑环境的 GUI Agent 评估与 RL 训练一体化开放平台（MAI-Gym: An Open All-in-One Platform for GUI Agent Evaluation and RL Training across Mobile and Computer Environments）](https://huggingface.co/papers/2610.20939)**
开源 GUI Agent 评估与强化学习训练一体化平台，解决跨移动与桌面环境训练成本高、评测割裂的难题。
