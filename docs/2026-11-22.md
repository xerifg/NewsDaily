**📄 论文速递**

今日论文聚焦具身智能评测基准、世界模型与 VLA 推理加速，世界模型与动作效果的因果一致性成为共同关切。

1. **[Mind2Act World：机器人操作中具身心智、物理动作与心智-动作组合的诊断基准](https://huggingface.co/papers/2611.26444)**
提出面向机器人操作的诊断性基准，分别评测基于历史的认知推理、物理动作执行以及二者组合能力，填补具身智能分项评测空白。

2. **[ZeroVLN：无需对 VLM 大脑做监督微调的视觉语言导航学习](https://huggingface.co/papers/2611.26414)**
提出不微调 VLM 主干、仅依赖可学习动作头的导航范式，降低视觉语言导航对导航域标注数据的依赖。

3. **[扩散 Transformer 中的 RL 后训练本质上是激活引导](https://huggingface.co/papers/2611.26627)**
分析表明扩散 Transformer 的强化学习后训练效果可归因于激活层面的引导，为理解与简化 RL 后训练流程提供新视角。

4. **[学习哪些动作会改变什么：面向动力学忠实世界模型的动作效果匹配](https://huggingface.co/papers/2611.25980)**
提出动作效果匹配目标，约束世界模型预测的动作后果与真实动力学一致，缓解"画面逼真但动力学失真"的问题。

5. **[AutoMaster：让同一模型成为更好的教师以实现自主后训练](https://huggingface.co/papers/2611.26510)**
让模型自身充当教师进行自主后训练，规避成功轨迹中隐含的错误假设与无效重复，提升后训练信号质量。

6. **[WAM-Policy：面向四足机器人移动操作的在策略蒸馏世界动作模型](https://huggingface.co/papers/2611.24011)**
针对三足行走、前肢操作的四足移动操作任务，用世界动作模型结合在策略蒸馏实现语言指令跟随，填补该形态下的策略空白。
