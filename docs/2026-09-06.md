**📄 论文速递**

1. **[RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning](https://huggingface.co/papers/2609.03199)**
   提出互联网规模的数据引擎RoboTok，用于人类演示检索与灵巧操作学习，解决机器人数据采集昂贵且难以覆盖长尾任务的问题。

2. **[Knowing When Not to Reuse: Conditional Experience Transfer in Autonomous LLM Post-Training](https://huggingface.co/papers/2608.26730)**
   研究自主LLM后训练中的条件经验迁移问题，提出判断何时不应复用旧经验的方法以提升模型适应新领域的能力。

3. **[Scal3R: Learning Efficient Multi-Relative Pose Query for Scalable Online 3D Reconstruction](https://huggingface.co/papers/2609.04201)**
   提出Scal3R方法，通过学习高效的多相对位姿查询实现可扩展的在线3D重建，解决长视频场景下固定首帧锚点外推导致的性能退化。

4. **[Editable Visual Design](https://huggingface.co/papers/2609.04034)**
   针对扩散模型端到端生成产生扁平位图、文字易错且不可编辑的问题，提出可编辑视觉设计方案。

5. **[DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training](https://huggingface.co/papers/2609.04094)**
   提出DRACO框架，通过动态评分细则实现细粒度信用分配，解决长周期智能体训练中缺乏程序化检查器时的奖励建模难题。

6. **[WorldReward: Reward Modeling for Camera-Conditioned World Models](https://huggingface.co/papers/2609.03952)**
   提出WorldReward奖励建模方法，用于相机条件世界模型，确保生成视频中指令动作引发预期场景变化的同时保持外观、几何与时间动态一致性。

7. **[FlashRender: Few-Step Generative Rendering via Camera-Controlled Video MeanFlow](https://huggingface.co/papers/2609.03563)**
   提出FlashRender少步生成渲染框架，通过相机控制的视频MeanFlow在数秒内沿目标相机轨迹重拍源视频。

8. **[Using Grounded Theory for Agent Behavior Analysis at Scale](https://huggingface.co/papers/2608.30391)**
   提出将扎根理论应用于大规模智能体行为分析，可扩展到数千条轨迹并发现长任务中的新模式。
